01 / Projects [BUILD]
GENERATIVE MUSIC · WEB AUDIO · RESEARCH

Continuo

Music that composes itself, live, in your browser. Continuo plans a form, derives each phrase's harmony backward from its cadence with a Rohrmeier-style functional grammar, develops motifs over it, and writes the parts with counterpoint and voice-leading search — seconds before you hear them. Runs entirely client-side on the Web Audio API. Start it with npm ci.

TypeScript Web Audio API Counterpoint Ablation Eval MIT 94% CADENCES

Citropy — Sway

Claude Code, Codex, OpenCode, Cursor and Pi in one desktop app. Each conversation picks its own agent, model and permission mode, and can switch agents without losing its history. Hunk-level diff review, AI-written commits in a separate session, SSH and Docker workspaces, plus per-conversation token and allowance tracking.

Electron TypeScript Node.js Git Plumbing SSH / Docker
NEXT.JS · POSTGRES · SYNTHESISED RADIO

Goodnight Club

A night-owl journal built on Next.js and Postgres, with a night-radio engine written in raw Web Audio that scores and plays generative tracks in the tab. Guestbook, RSS feed and rate-limited API routes, Drizzle-typed schema, self-hosted typography and a warm CRT palette that stays legible in the dark.

Next.js TypeScript Drizzle ORM Postgres Web Audio LIVE
